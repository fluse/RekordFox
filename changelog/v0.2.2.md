RekordFox 0.2.2 – Release Notes

🎧 New Features
Local playlists: create your own playlists and drag tracks into them from other playlists.
Spotify playlist syncing.
Preview player now shows BPM and supports pitch control.
Beatgrid analyzing, plus more precise BPM analysis.
Onboarding screen on first launch — walks through core features and offers a one-click example playlist import (reachable again anytime from Settings → Onboarding).
Four new color schemes: forest, amber, cyan, and fuchsia.
USB stick auto-detection: connected sticks are now picked up automatically, with a manual refresh option and a step-by-step CDJ/rekordbox USB preparation guide (PioneerInitGuide).
Tracks can now be removed from playlists.
Sidebar playlist rows reworked: OAuth-connected playlists get a distinct connect icon (vs. plain YouTube-URL playlists), sync/download status merged into a single indicator, per-playlist track counts shown, and edit/rename/refresh/delete moved into the tracklist header for a cleaner sidebar.
Better highlighting for the currently playing track, and auto-scroll when dragging a track to reorder it in a list.
Default UI language changed from German to English for new installs.
🛠️ Improvements & Fixes
Rewrote Pioneer/CDJ export: playlists are now merged directly into rekordbox's export.pdb (instead of a side SQLite DB), so they actually show up in the CDJ playlist menu; analysis files follow rekordbox's own folder convention, and the original pdb is safely backed up and written atomically.
Fixed corrupted waveform analysis files (ANLZ0000.DAT/.EXT) that could make CDJs report the exported library as broken: the file/tag headers were missing a required length field and used a non-standard waveform layout; exports now write spec-correct PWAV/PWV3 tags.
Pioneer/CDJ export now writes a beat grid (ANLZ PQTZ tag) alongside the waveform, synthesized from the track's analyzed BPM/grid phase, so CDJs can beat-sync and quantize against exported tracks.
Fixed macOS USB/CDJ export failures and a launch crash: exports now use a data-only stream copy instead of fcopyfile, which was failing on exFAT/FAT32/network volumes; added the required macOS entitlements (removable-volume access, disabled library validation) so signed builds no longer crash on launch or freeze the UI during large exports.
Fixed the exporter blocking the main thread during export.
Fixed track paths not updating correctly after moving the library folder.
Fixed YouTube playlist link state when no account is linked.
Restructured the internal database file into more readable/maintainable files, plus general code restructuring and refactors.
Added a self-signing/code-signing setup for builds, with several follow-up fixes to the build and signing configuration.
Added tests around BPM analysis.
Various lint fixes and internal cleanup.
